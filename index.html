📋 使用说明

  • 输入端规则：上传暖通专业工程量清单 Excel（.xlsx/.xls），A列=序号、B列=项目名称（含型号/规格/风量）、C列=数量，首行可为表头；系统按项目名称自动识别并套用清单与定额。名称中须写全关键参数——风机/空调器/油烟净化写风量（如 5000m³/h、L=5000），风口/风阀/消声器/风管写尺寸（如 800×400、φ400），静压箱写长×宽×高（如 1200×400×250）；输出页「类型/选型」列可手动调整（如风机轴流/离心），结果支持广联达 / 建经科技两种格式导出。
  • 定额依据：2020预算基价第九册（通风空调工程）——通风机 9-233~243（离心/轴流按风量分档）、组合式空调机组·新风机组 9-257~264、吊顶/落地/墙上式空调器 9-248/251/254、风机盘管 9-265~268、变风量末端 9-269、油烟净化 9-271~274、风阀 9-63~85、人防密闭阀 9-423~429、风口 9-86~154、消声器 9-190~204、静压箱 9-213~215、风管 9-1~9-11（镀锌薄钢板圆形 9-1~9-5 按直径、矩形 9-6~9-11 按长边长分档，单位 10m²）、净化风管 9-279~9-282、不锈钢板风管 9-293~9-297、塑料风管 9-322~9-330、玻璃钢风管 9-363~9-370、复合型酚醛风管 9-385~9-392、柔性软风管 9-39~9-43、通风管道场外运输 9-56；第一册（机械设备安装工程）——冷水机组 1-1130~1-1152（活塞/离心/螺杆，按制冷量分档）、热泵冷（热）水机组 1-1153~1-1164、玻璃钢冷却塔 1-1295~1-1303（按处理水量分档）；第八册（给排水采暖燃气工程）——管道 8-1~8-490 系列（室内外 × 介质 × 连接方式 × 管径）、管道消毒冲洗 8-490~、沟槽管件 8-220~、水系统阀门螺纹阀门 8-579~8-584（DN15~50）/ 焊接法兰阀 8-620~8-629（DN65~400）、法兰浮球阀 8-612~8-616、法兰液压水位控制阀 8-645~8-649、自动排气阀·手动放风阀 8-682、散热器温控阀 8-686；第七册（消防工程）——管道支吊架制作安装 7-138（单位 100kg）；第十一册（刷油防腐绝热工程）——管道橡塑保温壳安装 11-582（D133以内）、带铝箔离心玻璃棉安装 通风管道 厚度40mm 11-647。
  • 通风管道（本批新增）：名称含镀锌钢板 / 风道 / 通风管道等字眼即视为常规碳钢通风管道，清单统一 030702001 碳钢通风管道；矩形按长边长套 9-6~9-11（320/450/1000/1250/2000/4000mm以内），如 矩形风道600*400、1000*400 均套 9-8 镀锌钢板矩形风管 长边长1000mm以内；圆形按直径套 9-1~9-5（320/450/1000/1250/2000mm以内），清单编码不变。同一定额的多条风管自动合并工程量，项目名称替换为定额名称（如 600×400 200㎡ + 800×400 600㎡ + 1000×400 400㎡ → 合并为 9-8，工程量 1200㎡）。板厚随档位取 0.5/0.6/0.75/1.0/1.2mm，主材按镀锌钢板信息价计。
  • 各类材质风管（本批新增）：按名称关键词分流，分档口径各不相同，请对号入座——
    • 净化风管：含 净化 / 进口 → 清单 030702001，定额 9-279~9-282 按周长分档（800 / 2000 / 4000 / 4000mm以外）。如 净化风道800*200 周长2000、800*100 周长1800，均套 9-280 并合并。
    • 不锈钢板风管：含 不锈钢 → 清单 030702003，定额 9-293~9-297 按直径×壁厚分档（200×2 / 400×2 / 560×2 / 700×3 / 700以外×3）；名称未注壁厚时统一套最小档 9-293，矩形执行圆形子目（按长边长）。
    • 塑料风管：含 塑料 / PPR → 清单 030702005；圆形 9-322~9-325 按直径（300/630/1000/2000×3~6），矩形 9-326~9-330 按周长（1300/2000/3200/4500/6500×3~8）。
    • 玻璃钢风管：含 玻璃钢 → 清单 030702006；圆形 9-363~9-366 按直径（200/500/1120/1120以外），矩形 9-367~9-370 按周长（800/2000/4000/4000以外）。
    • 复合型风管：含 复合 / 酚醛 → 清单 030702007；圆形 9-385~9-388 按直径（300/630/1000/2000），矩形 9-389~9-392 按长边长（300/630/1000/1000以外，注意不是周长）。
    • 柔性软风管：含 软风管 / 软管 / 软连接 → 清单 030702008，定额 9-39~9-43 按直径（150/250/500/710/910），单位 m（按中心线长度）。
    以上各类均按同一定额自动合并工程量、项目名称替换为定额名称；名称无尺寸时按该类最小档计列并标黄提示。
  • 制冷设备（本批新增）：清单 030112001 冷水机组，按名称分三类并按制冷量 kW 分档——活塞式 1-1130~1-1137（60/125/240/360/600/935/1200/1500kW）、离心式 1-1138~1-1145（350/600/900/1200/1500/1800/2300/3000kW）、螺杆式 1-1146~1-1152（240/350/600/900/1200/1800/2300kW）；名称未注类别按活塞式、未注制冷量按本类最小档计列，可在「类型/选型」列切换活塞/离心/螺杆。030112003 热泵机组 对应 1-1153~1-1164（10/20/35/60/120/180/240/300/350/480/600/700kW）；030112006 冷却塔 对应 1-1295~1-1303（处理水量 30/50/70/100/150/250/300/500/700m³/h）。设备价按国产中高档品牌询价，价格旁标注品牌。
  • 水系统管道（本批新增）：暖通站管道部分的清单、定额、主材价计取原则与给排水站完全一致——清单 031001001~031001008（铸铁/镀锌/无缝/焊接/铜/不锈钢/复合/塑料），定额按第八册（给排水采暖燃气工程）分「室内/室外 × 介质 × 连接方式 × 管径」匹配；每条管道自动附加管道消毒冲洗 8-490~，沟槽（卡箍）连接另附加沟槽管件 8-220~（按6m定尺估算数量）。名称只写「空调水/冷冻水/冷却水/冷凝水/热水管道」未注材质时，按镀锌钢管处理并标黄提示。输出页「类型/选型」列给出室内/室外与连接方式两个下拉，可手动校正。
  • 水系统阀门（本批新增）：名称含阀、Y型过滤器、过滤器、软接头、橡胶软接头、补偿器、波纹补偿器等关键词，且带管径（如 DN100）时，清单统一 031002001 金属阀门——DN15~DN50 套螺纹阀门 8-579~8-584，DN65~DN400 套焊接法兰阀 8-620~8-629，DN>400 取 8-629。价格优先取信息价（闸阀/截止阀/蝶阀/止回阀/Y型过滤器/球阀），无信息价的阀种（软接头、补偿器、平衡阀等）按市场价并标注参考品牌。四类特殊阀门单独编码：031002303 自动排气阀＋8-682（含手动放风阀，信息价）、031002306 散热器温控阀＋8-686（市场价）、031002301 法兰浮球阀＋8-612~8-616（DN32/50/80/100/150，市场价）、031002302 液压水位控制阀＋8-645~8-649（DN50/80/100/150/200，市场价）。风阀（防火阀/排烟阀/多叶调节阀等）仍走 030703001，系统按是否带 DN 与风管截面尺寸自动区分。
  • 管道支架（本批新增·自动补项）：只要清单中存在任意管道，系统在所有管道行之后自动补一行 031301005 支/吊架、基础型钢＋定额 7-138 管道支架制作、安装（定额单位 100kg），主材按型钢信息价 4.20 元/kg 计入。工程量按管道长度×管径分档含量估算（DN≤50 0.45、DN65~100 0.90、DN125~200 1.50、DN250~400 2.40、>400 3.20 kg/m），请按图纸支架实际重量调整；原表已带支架行时不重复新增。
  • 保温绝热（本批新增）：名称含 橡塑 → 清单 031208002 其他管道绝热＋定额 11-582 管道橡塑保温壳安装（D133以内），主材1000 元/m³；名称含 玻璃棉 / 离心玻璃棉 → 清单 031208002＋定额 11-647 带铝箔离心玻璃棉安装 通风管道 厚度40mm，主材450 元/m³。工程量按保温体积（m³）计；若单位列填 m²（风管面积）或 m（管道长度），系统自动折算体积（橡塑厚按30mm、玻璃棉按40mm）。
  • 通风管道场外运输：只要清单中出现任意风管，系统在末尾自动补一行 030702301 通风管道场外运输 ＋ 定额 9-56，工程量＝全部风管展开面积合计（柔性软风管按 π×直径×长度 折算），不计主材价；若原表已带该行会自动去重，不重复计列。
  • 价格依据：镀锌钢板风管、净化风管主材按天津市当月信息价（镀锌钢板除税价，按板厚档换算 元/㎡）；不锈钢板、塑料板按市场板价（元/kg × 密度 × 壁厚）换算，玻璃钢、酚醛复合、柔性软风管按成品市场价计入，同类风管单价保持一致；其余设备材料参考天津市当月信息价及合理市场价标准进行组价，单价均可在 data/prices.js 调整。
