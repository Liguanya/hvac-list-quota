# 暖通专业智能组价系统

原「风口风阀自动组价系统」与「风机设备自动组价系统」合并版。输入 A 列序号 / B 列项目名称 / C 列数量，自动匹配天津 2025 计价规范清单编码、2020 预算基价第九册（通风空调工程）定额子目与主材参考价，支持广联达、建经科技两种格式导出。

## 覆盖范围

- 通风空调设备：通风机（轴流/斜流/混流 9-239~243、离心 9-233~238）、卫生间通风器 9-247、组合式空调机组/新风机组 9-257~264、吊顶式 9-248、落地式 9-251、墙上式 9-254、风机盘管 9-265~268、变风量末端 9-269、油烟净化器 9-271~274、空气加热器（冷却器）9-230、除尘设备 9-275
- 通风管道部件：风口 9-86~93、方形散流器 9-102~104、圆形散流器 9-105~107、带调节阀百叶 9-122~127、圆形带阀风口 9-128~134、板式排烟口 9-140~146、多叶送/排烟口 9-147~154
- 风阀：防火阀 9-82~85、蝶阀 9-63~67、止回阀 9-68~71、斜插板阀 9-72~75、对开多叶调节阀/密闭阀/定风量阀 9-76~81、超压排气阀门 9-420、人防手动密闭阀 9-423~429
- 消声器 9-190~204、静压箱 9-213~215
- 通风管道（碳钢）：清单统一 `030702001 碳钢通风管道`，定额 9-1~9-11（单位 10m²）
  - 矩形风管（按**长边长**分档）：9-6 ≤320、9-7 ≤450、9-8 ≤1000、9-9 ≤1250、9-10 ≤2000、9-11 ≤4000mm
  - 圆形风管（按**直径**分档）：9-1 ≤320、9-2 ≤450、9-3 ≤1000、9-4 ≤1250、9-5 ≤2000mm
  - 名称含「镀锌钢板 / 风道 / 通风管道」即识别为常规碳钢风管；同一定额的多个规格**自动合并工程量**，项目名称替换为定额名称
  - 板厚随档位取 0.5 / 0.6 / 0.75 / 1.0 / 1.2mm

## 价格口径（统一标准，同类单调递增）

- 消声器：周长(m) × 560 元/m × 类型系数（微穿孔板 1.0、阻抗式 1.15、管式 0.85）
- 人防密闭阀：直径(mm) × 2.6 元/mm，下限 380 元，电动执行机构另加 400 元
- 风管：**天津市当月信息价**（镀锌钢板除税价，元/t）× 板厚 × 7.85kg/㎡·mm → 元/㎡
  - δ0.5→16.25、δ0.6→19.08、δ0.75→23.37、δ1.0→30.22、δ1.2→35.98 元/㎡
  - 信息价原始值（除税元/t）：δ0.5 4137.90、δ0.6 4053.50、δ0.75 3969.16、δ1.0 3846.65、δ1.2 3820.00，改价只改 `data/prices.js` 的 `duct.plates`
- 补齐原无参考价的设备：吊顶/落地/墙上式空调器、多联机（室内机 kW、室外机 HP）、变风量末端、除湿机、过滤吸收器、空气加热器、除尘设备

## 未匹配兜底

名称无法对应标准清单/定额的项目（支架、软接、保温、未收录设备）统一套补充清单 `030806801`，定额顺序编号 `补1`、`补2`、`补3`……，行内切换类型不重排编号。

风管例外：清单固定 `030702001`，仅缺尺寸时不套补充清单，保留清单编码、定额留空待手选（黄色提示行）。

## 手动选型

输出表「类型/选型」列可手动切换，切换后定额与主材价实时重算：风机类型（轴流/离心）、空调器型式、风机盘管安装方式、风口型式、风阀型式、消声器型式、风管形状（矩形/圆形）。

## 加载性能

- 首屏只加载 `js/xlsx.mini.min.js`（250KB，gzip 后约 79KB），替代原 `xlsx.full.min.js`（881KB / gzip 316KB），首屏就绪时间约缩短 3/4
- 精简库支持 .xlsx 读写；`.xls`（BIFF）老格式与个别特殊编码文件，在**上传时**才按需补载 `js/xlsx.full.min.js` 重试，用户无感
- 状态栏新增黄色「加载中」提示（`status-loading`）
