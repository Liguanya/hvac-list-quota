# 暖通专业智能组价系统

原「风口风阀自动组价系统」与「风机设备自动组价系统」合并版。输入 A 列序号 / B 列项目名称 / C 列数量，自动匹配天津 2025 计价规范清单编码、2020 预算基价第九册（通风空调工程）/第一册（机械设备安装工程）/第八册（给排水采暖燃气工程）定额子目与主材参考价，支持广联达、建经科技两种格式导出。

## 价格口径（统一标准，同类单调递增）

- 制冷设备：国产中高档品牌询价，单价 = 档位基准价 × 品牌系数（格力 1.00 / 美的 0.96 / 海尔 0.93；热泵 格力 1.00 / 美的 0.96 / 清华同方 0.94；冷却塔 良机 1.00 / 金日 0.94 / 华强 0.90），basis 中列出三家参考价
- 管道：天津市造价信息除税价（元/m），按公称直径就近取档，缺档时取相邻档并在悬停说明中标注

- 消声器：周长(m) × 560 元/m × 类型系数（微穿孔板 1.0、阻抗式 1.15、管式 0.85）
- 人防密闭阀：直径(mm) × 2.6 元/mm，下限 380 元，电动执行机构另加 400 元
- 风管：**天津市当月信息价**（镀锌钢板除税价，元/t）× 板厚 × 7.85kg/㎡·mm → 元/㎡
  - δ0.5→16.25、δ0.6→19.08、δ0.75→23.37、δ1.0→30.22、δ1.2→35.98 元/㎡
  - 信息价原始值（除税元/t）：δ0.5 4137.90、δ0.6 4053.50、δ0.75 3969.16、δ1.0 3846.65、δ1.2 3820.00，改价只改 `data/prices.js` 的 `duct.plates`
- 其他材质风管（无官方信息价，按合理市场价，同类风管单价一致）
  - 不锈钢板 304：15.5 元/kg × 7.93kg/㎡·mm × 壁厚 → 2mm 245.83、3mm 368.75 元/㎡
  - 硬聚氯乙烯板：10 元/kg × 1.4kg/㎡·mm × 壁厚 → 3mm 42、4mm 56、5mm 70、6mm 84、8mm 112 元/㎡
  - 玻璃钢成品风管 δ4mm以内：65 元/㎡；酚醛复合板成品风管（板厚20mm）：28 元/㎡
  - 柔性软风管：按直径 ≤150→12、≤250→18、≤500→30、≤710→45、≤910→60 元/m
- 补齐原无参考价的设备：吊顶/落地/墙上式空调器、多联机（室内机 kW、室外机 HP）、变风量末端、除湿机、过滤吸收器、空气加热器、除尘设备

## 未匹配兜底

名称无法对应标准清单/定额的项目（支架、软接、保温、未收录设备）统一套补充清单 `030806801`，定额顺序编号 `补1`、`补2`、`补3`……，行内切换类型不重排编号。

风管例外：各类风管清单固定（030702001 / 030702003 / 030702005 / 030702006 / 030702007 / 030702008），仅缺尺寸时不套补充清单，按该类**最小定额档**计列并标黄提示核对。

制冷设备、管道例外：清单已固定（030112001 / 030112003 / 030112006 / 031001001~008），缺制冷量、处理水量、管径时只按最小档取定额、不改清单。

## 手动选型

输出表「类型/选型」列可手动切换，切换后定额与主材价实时重算：风机类型（轴流/离心）、空调器型式、风机盘管安装方式、风口型式、风阀型式、消声器型式、风管形状（矩形/圆形，净化/不锈钢/塑料/玻璃钢/复合/柔性各自独立选项）、冷水机组型式（活塞/离心/螺杆）；管道行为**室内/室外**与**连接方式**两个下拉（连接方式随材质与部位联动，切换后自动校正并重算定额）。

## 加载性能

- 首屏只加载 `js/xlsx.mini.min.js`（250KB，gzip 后约 79KB），替代原 `xlsx.full.min.js`（881KB / gzip 316KB），首屏就绪时间约缩短 3/4
- 精简库支持 .xlsx 读写；`.xls`（BIFF）老格式与个别特殊编码文件，在**上传时**才按需补载 `js/xlsx.full.min.js` 重试，用户无感
- 状态栏新增黄色「加载中」提示（`status-loading`）
